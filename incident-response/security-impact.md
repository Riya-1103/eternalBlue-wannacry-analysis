## Security Impact Assessment
The exercise highlighted the potential consequences of a ransomware attack on an endpoint.
### Confidentiality
Ransomware incidents can be associated with additional malicious activities, including data theft. Data exfiltration was not verified in this experiment.
### Integrity
The observed file encryption or inaccessibility affected the availability of original file contents.
### Availability
The inability to access affected files demonstrated a direct impact on system availability.
### Overall Impact
The experiment demonstrated how an attacker who obtains unauthorized access to a vulnerable endpoint may introduce malicious software and disrupt normal system operations.
